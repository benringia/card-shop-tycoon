# Shop Jobs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Levelled cards work in the shop as Restocker or Cashier (1 slot at shop Lv 10, +1 with a Robux pass), walking around as placeholder creatures, with SPD = speed, Power = fewer mistakes, and 2 XP per minute.

**Architecture:** Pure, Lune-tested rules (`Util/JobRules`) and save migration (`Migrations` v6). `JobService` owns workers per player and runs each job as a loop on top of narrow new APIs in StockService, RegisterService and CardService, so workers and the owner share the same boxes, checkouts, cash and saves. NPC walking is extracted from CustomerService into `Util/NpcMotion` and reused. A `MonetizationService` answers "does this player have the Extra Job Slot pass". The client gets a Jobs panel and binder "Assign to job".

**Tech Stack:** Roblox Luau (`--!strict`), Rojo 7.7.1, Lune 0.11.

**Spec:** `docs/superpowers/specs/2026-10-21-shop-jobs-design.md`

## Global Constraints

- Slot 1 at shop Lv 10; slot 2 needs the `ExtraJobSlot` pass; max 2; both may be the same job.
- `XP_PER_MINUTE = 2` per working card, only while the owner is online.
- Speed factor = clamp(SPD / 12, 0.6, 2.0); durations = base / factor; walk speed = 12 × factor.
- Mistake chance: 0.20 at Power ≤ 170, 0.03 at Power ≥ 485, linear between. Mistakes cost time only.
- Working cards are individual cards, locked: no display, condense, re-assign.
- Server authoritative; remotes validated and rate-limited; tunables in `Config/Jobs.luau` / `Config/Monetization.luau`.
- Placeholder creature: an R15 rig like customers, body tinted with the card's element colour, scaled by rarity, with a name/grade/level/job billboard. (Spec section 3 updated to match.)
- Commands: tests `"$USERPROFILE/.rokit/bin/lune.exe" run tests/run`; build; sourcemap; syntax check.

## Review Focus

1. **A working card leaving the binder** (displayed, condensed into, assigned twice, bought) → refused everywhere. Pinned in Task 3 (server checks) + Task 6 (UI hides it) + Studio step.
2. **Owner and worker racing for the same box or checkout** (owner picks up the box the restocker walks to; owner charges while the cashier scans) → no duplicate stock or double charge. Pinned in Task 5 (box/checkout ownership checks before every step).
3. **Owner leaves mid-job** (box carried by a restocker, checkout half scanned) → box back in saved boxes, checkout ends like today. Pinned in Task 5 (unload returns carried box) + Studio step 7.
4. **Saved jobs referencing missing/sold cards, unknown jobs, slot 2 without the pass** → dropped on load. Pinned in Task 2/5 tests and load code.
5. **Pass check failing** (MarketplaceService error) → treated as not owned, retried later; never errors. Pinned in Task 4 (pcall).

- [ ] **Step 4: Implement** `Util/JobRules.luau` (pure, no requires; callers pass `Config/Jobs`):

```lua
--!strict
-- Shop job maths: work speed from SPD, mistakes from Power, job slots. Pure so tests/ run it in Lune.
local JobRules = {}

type Config = {
	REFERENCE_SPD: number, SPEED_MIN: number, SPEED_MAX: number,
	MISTAKE_MAX: number, MISTAKE_MIN: number, MISTAKE_POWER_LOW: number, MISTAKE_POWER_HIGH: number,
	UNLOCK_LEVEL: number, FREE_SLOTS: number, PASS_SLOTS: number,
}

function JobRules.getSpeedFactor(config: Config, spd: number): number
	if spd ~= spd then
		return 1
	end
	return math.clamp(spd / config.REFERENCE_SPD, config.SPEED_MIN, config.SPEED_MAX)
end

function JobRules.getDuration(config: Config, baseSeconds: number, spd: number): number
	return baseSeconds / JobRules.getSpeedFactor(config, spd)
end

function JobRules.getMistakeChance(config: Config, power: number): number
	local span = config.MISTAKE_POWER_HIGH - config.MISTAKE_POWER_LOW
	local t = math.clamp((power - config.MISTAKE_POWER_LOW) / span, 0, 1)
	return config.MISTAKE_MAX + (config.MISTAKE_MIN - config.MISTAKE_MAX) * t
end

function JobRules.getSlotCount(config: Config, level: number, hasPass: boolean): number
	if level < config.UNLOCK_LEVEL then
		return 0
	end
	return config.FREE_SLOTS + (if hasPass then config.PASS_SLOTS else 0)
end

return JobRules
```

- [ ] **Step 4: JobService**:
  - State per player: `slots = { [slot] = { beastId, job, model, status, running } }`.
  - `load`: from `data.jobs`, keep entries with a known job, slot ≤ `getSlotCount(level, HasPass)`, an existing beast, first per beast; `CardService.SetWorking`; spawn workers. `save`: write `jobs`. `unload`: stop loops, return worker boxes, destroy models.   - Worker model: `NpcMotion.createRig` at the shop entry, tinted to `Cards.ELEMENTS[card.element]`, scaled by `RARITY_SCALE`, `WalkSpeed = WALK_SPEED × factor`, billboard `"{name}\nGrade {g} · Lv {l}\n{job}"`.
  - **Restocker loop:** pick a waiting box whose product some shelf takes (`PlacementService.GetShelves` with same product and space, else empty shelf accepting it); walk to pad; `TakeWaitingBox` (skip if the owner took it); weld to the rig; walk to shelf; mistake roll → `ReturnBox`, status "Dropped a box!", restart; wait `getDuration(STOCK_SECONDS)`; `AddStock`; `ConsumeUnits`; leftovers → next shelf or `ReturnBox`. Idle statuses as in the spec; re-check every `IDLE_RECHECK_SECONDS`.
  - **Cashier loop:** when `GetCheckout(plot)` exists and the owner isn't at the register: walk behind the register; per item: wait scan time, mistake roll → wait again; `ScanNext`; when done `ChargeByWorker`. Owner at the register → step aside point, status "Waiting: you're at the register".
  - **XP tick:** every 60 s, each slot's beast `CardService.AddXP(player, beastId, XP_PER_MINUTE)`; billboard and status refresh.
  - Card gone (sold/condensed into is fine; missing beast) → slot freed, model removed.
