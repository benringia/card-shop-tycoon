# Main Town and Shop Shells Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the main game's grey plots into a cozy stylized town with themed open-front shops, built in code
with every decoration swappable by dropping a model file into `assets/props/`.

**Architecture:** A pure `TownLayout` module turns plot geometry and portal/spring spots into a fixed list of
prop placements (Lune-tested). A server `Props` util places a prop from `ServerStorage.PropModels` or builds a
part fallback. `TownService` builds ground, decor, portal frames and lighting; `PlotService` builds each shop's
shell; `PlacementService` gives Products shelves the `Shelf` prop; a client `TownController` hides the roof of the
shop you stand in.

**Tech Stack:** Luau (`--!strict`), Rojo 7.7.1, Lune 0.11 tests.

**Spec:** `docs/superpowers/specs/2026-10-25-main-town-design.md`

## Global Constraints

- Every tunable number lives in `src/shared/Config/Town.luau`; it is **plain data** (colours as `{ r, g, b }`
  tables, positions as `{ x, z }`) so Lune can load it. No magic numbers in services.
- Main game only: nothing in this plan runs in the Frontier place (`Place.isFrontier()`).
- Walls sit outside the 40×40 floor. The placement grid, saved layouts, data schema and NPC paths do not change.
- Decor is anchored, CanTouch off; non-colliding decor is also CanQuery off.
- Props: strip scripts, sounds, prompts, click detectors, tools; > `MAX_PROP_PARTS` (150) parts → fallback.
- `assets/props` holds no scripts (Lune gate).
- UI/sign text: plain ASCII plus `·` and emoji.
- Commands: tests `"$USERPROFILE/.rokit/bin/lune.exe" run tests/run < /dev/null`; build
  `rojo build -o <scratch>/test.rbxl`; after each task the full suite and both builds (`default.project.json`,
  `frontier.project.json`) pass.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. A prop file whose model has no parts, zero height, or a huge part count → fallback placed, server does not error.
2. Products shelf placed, moved, rotated, sold, and reloaded from save → the `Shelf` prop follows the hitbox and
   is destroyed with it; prompts and the label still work on the invisible part.
3. A plot released and re-claimed → floor goes back to `FREE_COLOR` then to the theme floor colour; sign text
   resets; walls keep the theme.
4. Character dies or respawns inside a shop, or leaves through a side gap → roof hidden only while inside the
   footprint; no stale hidden roof.
5. Frontier place boot → TownService and TownController do not start; Frontier lighting unchanged.

Items 1 and 5 are pinned by Task 3's and Task 4's steps; 2–4 are Studio checks in Tasks 6, 5 and 7.

### Task 2: TownLayout (pure)

**Files:**
- Create: `src/shared/Util/TownLayout.luau`, `tests/TownLayout.spec.luau`
- Modify: `tests/run.luau` (register `TownLayout`), CLAUDE.md test list

**Interfaces:**
- Consumes: `Config/Town` (Task 1).
- Produces:

```lua
export type Point = { x: number, z: number }
export type World = {
	plotCount: number, perRow: number, plotWidth: number, plotDepth: number, gap: number, streetWidth: number,
	portals: { Point }, spring: Point, springRadius: number,
}
export type Placement = { slot: string, x: number, z: number, yaw: number } -- yaw in degrees, 0 = facing -Z
export type Rect = { minX: number, maxX: number, minZ: number, maxZ: number }

TownLayout.build(world: World, town: typeof(Town)): { Placement }
```

Placement rules, from the spec layout (sides are `-1` and `1`; street half-width `h = streetWidth / 2`):
lamps at each gap centre and at each row end ± `ROW_END_LAMP_OFFSET`, z = `side * (h - LAMP_INSET)`, yaw facing
the street centre; benches at `BENCH_RADIUS` around the spring at `BENCH_ANGLES`, yaw facing the spring; a
`Flowers` beside each bench at angle + `FLOWER_ANGLE_OFFSET`; per gap a `Bush` at mid-depth, a `Crate` and
`Barrel` at depth `GAP_CRATE_DEPTH` from the front, x ∓ `GAP_CRATE_SPREAD`; `Fence` sections every
`FENCE_SECTION` along x ±`FENCE_HALF_LENGTH` at z = `side * (h + plotDepth + FENCE_OFFSET)`, yaw 0/180 by side;
trees every `TREE_SPACING` at z = `side * (h + plotDepth + TREE_OFFSET)`, cycling `TREE_SLOTS`; a tree at each
(±`STREET_END_TREE_X`, ±`STREET_END_TREE_Z`); per portal a `Portal` at the spot (yaw facing x = 0) and two
`Rock`s at `PORTAL_ROCK_BACK` away from the town and ±`PORTAL_ROCK_SIDE`. The test file builds `World` from
literal numbers copied from `Config/Plots`, `Wild.PLAZA_PORTAL`, `Places.FRONTIER_PORTAL`, `Pvp.ARENA_PORTAL`,
`Wild.SPRING` and `Combat.SPRING_RADIUS` (Plots holds Color3, so Lune can't load it; say so in a comment).

### Task 3: Props util

**Files:**
- Create: `src/server/Util/Props.luau`

**Interfaces:**
- Consumes: `ServerStorage.PropModels`, `Config/Town.SLOTS`, `Config/Town.MAX_PROP_PARTS`.
- Produces:

```lua
Props.place(slot: string, at: CFrame, parent: Instance): Model -- bottom centre on `at`, scaled to SLOTS[slot].height
Props.fit(slot: string, size: Vector3, at: CFrame, parent: Instance): Model -- scaled to fit inside `size`, bottom centre on `at`
Props.color(rgb: { number }): Color3 -- { r, g, b } table to Color3 (Town config colours)
```

`place`/`fit` share one path: find the source; if it is missing, not a Model, has no BaseParts, more than
`MAX_PROP_PARTS` BaseParts, or a bounding-box height < 0.05, or the clone or `ScaleTo` errors (pcall), use the
slot's fallback builder (a Model of parts, made at the slot's size, same pivot rule). Otherwise clone, destroy
every `LuaSourceContainer`, `Sound`, `ProximityPrompt`, `ClickDetector`, `Tool`; apply `YawOffset`; `ScaleTo`
(height ratio for `place`, smallest axis ratio for `fit`); set `WorldPivot` to the bounding-box bottom centre;
`PivotTo(at)`; anchor all parts, set CanCollide from the slot, CanTouch false, CanQuery = collide. Model name =
slot. Fallbacks per the spec list; a slot with no named fallback gets a plain box.

### Task 7: Roof hiding (client)

**Files:**
- Create: `src/client/Controllers/TownController.luau`
- Modify: `src/client/init.client.luau` (main-game branch only)

**Interfaces:**
- Consumes: `workspace.Plots.Plot<N>.Floor` and `.Roof` (Task 5), `Town.ROOF_CHECK_SECONDS`.
- Produces: `TownController.Start()`.

Loop every `ROOF_CHECK_SECONDS`: read the local character's HumanoidRootPart (none → show all roofs); find the
plot whose floor footprint (floor CFrame space, half size) holds it; set that roof's `LocalTransparencyModifier`
to 1 and every other roof to 0. Plots stream in: look roofs up each tick with `FindFirstChild`, never cache a
missing one.
